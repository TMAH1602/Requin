# Requin 0.1.1

An interface and usability update with the new angular Wedge shark logo.

- Menus close normally and support keyboard navigation.
- Numeric fields handle scientific notation and incomplete edits cleanly.
- Project saving and data exports use native save dialogs, with cancellation and error feedback.
- SVG exports retain their colors; PDF reports use native printing and a white print theme.
- Repeat imports and template selection work; new layers are selected automatically.
- Solves are debounced and serialized, with stale results clearly marked and stale exports disabled.
- Charts load separately and avoid unnecessary redraws.
- Updated icons across the app, favicon, macOS, and Windows.

The eight numerical regression tests, including MKC A1.4, and eight browser UI tests pass. Browser tests mock native dialog calls; OS dialog controls are not automated.

## Install or update on macOS

```sh
brew install --cask tmah1602/requin/requin
```

For an existing installation:

```sh
brew update
brew upgrade --cask tmah1602/requin/requin
```

Apple Silicon and Intel installers are included. The builds are unsigned and not Apple-notarized. If macOS blocks Requin, use **System Settings → Privacy & Security → Open Anyway** for the trusted download.
