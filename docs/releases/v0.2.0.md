# Requin 0.2.0

A guided scientific-workspace release focused on the Schottky diode lab workflow.

- A labeled, responsive workflow replaces the old icon-first navigation.
- First launch offers a hands-on tutorial, quick start, or skip; Settings can replay all twelve chapters or one section.
- Delta is the new default logo, with Wedge and a new anime-style Chibi available in Appearance.
- Version 2 workspaces embed measurements, study definitions, and fit settings while retaining older project and legacy-deck import.
- Bias, doping, and C–V studies provide overlays, device inspection, cancellation, and CSV/SVG exports.
- Measurement import adds explicit columns and units, linear/log plots, adjustable graph-selected fit regions, residuals, ideality/saturation extraction, and conditional barrier/area calculation.
- The core adds selectable Fermi–Dirac statistics, stabilized nonlinear updates, and surface-displacement C–V with per-point convergence tracking.
- Rendering and solve scheduling are leaner: heavyweight plots/equations load separately, hidden data stays unmounted, and live/study solves share one queue.

The release passes 18 browser/analysis tests and 13 numerical tests. Schottky checks cover every assigned bias/doping case, mesh refinement, and C–V doping recovery under both Boltzmann and Fermi–Dirac statistics. See `docs/SCHOTTKY_VERIFICATION.md` for assumptions and model boundaries.

## Install or update on macOS

```sh
brew install --cask tmah1602/requin/requin
```

For an existing installation:

```sh
brew update
brew upgrade --cask tmah1602/requin/requin
```

The Apple Silicon and Intel builds are unsigned and not Apple-notarized. Try to
open Requin once, then use **System Settings → Privacy & Security → Open Anyway**.
Apple normally shows the exception for about one hour. If it is absent, verify
the official tap and remove quarantine from Requin only:

```sh
brew info --cask tmah1602/requin/requin
xattr -dr com.apple.quarantine /Applications/Requin.app
open /Applications/Requin.app
```

Do not disable Gatekeeper globally. A managed Mac may require administrator approval.
