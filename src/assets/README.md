# Requin logo family

Delta is the default: `design/logo-concepts/03-delta.png` is its existing master.
`logos/` contains 256 px runtime derivatives for Delta, Wedge, and Chibi. Settings
selects the in-app logo and running window icon (also the macOS Dock icon).
Installed launcher/bundle icons and the initial favicon use Delta. Desktop PNG,
ICNS, and ICO assets are generated with `npm run tauri -- icon`.

`requin-chibi.png` is an AI-generated transparent anime-style master created with
the built-in image generation tool. Its generation brief was: an original compact
right-swimming athletic chibi shark, tapered body, angular fins and tail, small
determined eyes with a single highlight, tiny fang, teal/navy/off-white palette,
one cel-shaded shadow, 15% transparent padding; no gradients, 3D treatment, giant
baby eyes, or existing character. The source generation identifier is
`01a05968-3925-77b1-af5a-605aff8c435d/exec-b6a43d6f-99b5-417a-a1dc-df440a0da22d`.

## Wedge provenance

`requin-wedge.png` is the refined transparent master, generated with the built-in image generation tool from the selected [Wedge concept](../../design/logo-concepts/02-wedge.png).

Keep the square masters and their transparent padding intact. The `icons/`
derivatives now represent Delta, not Wedge.

## Final refinement prompt

Refine this selected angular Wedge shark-head logo for Requin. Keep the design nearly identical. Make it 12% smaller within the same square canvas so it has more empty padding. Simplify to one navy gill slash, remove the thin cyan highlight stripe along the top, and remove the tiny zigzag in the white lower jaw. Preserve the pointed right-facing snout, tall fin, small triangular white eye, one white tooth, navy outline and teal face. Clean solid flat fills. Transparent background. No pattern, no shadow, no glow. Square app logo.
