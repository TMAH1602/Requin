# Requin mascot

`requin-shark.png` is the transparent master image generated with the built-in
image generation tool. The app uses `icons/128x128.png`; the browser favicon
uses `icons/32x32.png`. Desktop icons are derived with `npm run tauri -- icon`.
Keep the master for future icon exports.

Generation prompt:

> Use case: logo-brand
> Asset type: desktop application logo and compact sidebar brand mark
> Primary request: Create a polished chibi shark mascot logo for Requin, a scientific 1D semiconductor simulation app.
> Scene/backdrop: genuinely transparent background, no badge or surrounding scene
> Subject: one cute compact baby shark in a confident three-quarter side pose, rounded body, tiny fins, friendly smile, bright intelligent eyes; subtle visual hint of science through one small electric teal spark motif integrated near the dorsal fin
> Style/medium: clean premium 2D mascot illustration, crisp vector-like silhouette, simple shapes, professional app-icon readability
> Composition/framing: centered, square, generous transparent padding, strong silhouette that remains recognizable at 32 px
> Color palette: deep navy outlines, teal and cyan body, pale mint belly, tiny violet accent
> Constraints: transparent background; no words, letters, equations, watermark, border, badge, gradients that muddy small-size readability; exactly one shark
> Avoid: realistic shark, aggressive teeth, clutter, photorealism, generic corporate clip art
